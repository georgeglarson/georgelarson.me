what it does

wiregraph turns raw packet captures into a live, interactive dashboard. Point it at a network interface or a pcap file and it builds a real-time topology: who's talking to whom, how much, over what protocols. Everything updates as packets flow in.

It started because I wanted a GUI for netgrep. netgrep finds the packets; wiregraph shows you the shape of the traffic. Together they cover the workflow from "something weird is happening on the network" to "here's exactly what's going on."

top talkers

Hosts ranked by traffic volume. Local vs remote IPs color-coded. Click to filter everything to that host's packets.

connection matrix

NxN grid of every host pair. Color intensity shows traffic volume, protocol colors show what kind. Click a cell to see the full conversation.

protocol breakdown

Click a protocol bar to isolate it across all panels. Click again to clear. TCP, TLS, DNS, UDP, HTTP, SSH, ICMP, DHCP, NTP all classified in real time.

stacked timeline

Per-protocol bytes/sec as a stacked area chart. Responds to filters — click a host and the timeline shows just that host's traffic composition over time.

packet inspection

Drawer opens on host click or search. Paginated packet table with timestamps, IPs, ports, protocols, sizes. Fetched from the backend with server-side filtering.

conversation analysis

Select two hosts to see directional byte/packet counts, protocol breakdown bars, traffic share, and timing. Shows who's sending vs receiving.

how it works

architecture

Single Rust binary. No JavaScript build step, no node_modules, no framework. The entire frontend is an embedded HTML string served from /. The backend captures packets via libpcap, parses them, and serves topology data over a JSON API. The frontend polls once per second and renders everything in vanilla JS + canvas.

Packet store uses a rolling window — configurable via --max-packets (default 1M) and --max-bytes (default 500MB). Oldest packets silently evict when the buffer fills. Runs indefinitely without growing memory.

Multi-interface capture: each interface gets its own thread, all feeding the same shared topology and packet store. Interactive CLI picker if you don't specify an interface.

the network tools story

These three projects cover different angles of the same problem: understanding network traffic.

netgrep — capture and search. grep for the network, with TCP reassembly and TLS decryption. The low-level tool you reach for when you know what you're looking for.

wiregraph — visualize. the dashboard you leave running to see the shape of traffic. built on the same packet parsing library as netgrep.

termshark — analyze. terminal UI for deep packet inspection with Wireshark display filters. for when you need to look at individual packets in detail.
