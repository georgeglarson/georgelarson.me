termshark

wireshark for the terminal. packet analysis with display filters, stream reassembly, and hex dump — no GUI required.

why

Wireshark is the gold standard for packet analysis but it needs a display server. When you're SSH'd into a production box investigating an issue, you don't have X11. You have a terminal.

termshark gives you Wireshark's display filter language, three-pane layout (packet list, protocol tree, hex dump), and stream reassembly — all in a terminal UI. Capture live or load a pcap. Apply the same filters you'd use in Wireshark. Export what you find.

wireshark display filters

Full Wireshark display filter syntax via tshark. tcp.port == 443, http.request.method == "POST", dns.qry.name contains "example" — the filters you already know.

three-pane layout

Packet list, protocol detail tree, and hex dump. Navigate with keyboard. Expand/collapse protocol layers. The same mental model as Wireshark, adapted for the terminal.

stream reassembly

Follow TCP and UDP streams. See the full conversation between two hosts reconstructed from individual packets. Essential for understanding application-layer behavior.

live capture + pcap

Capture live from any interface or load existing pcap files. Apply filters during or after capture. Export filtered packets to new pcap files for sharing or further analysis.

usage

# live capture on an interface
sudo termshark -i eth0

# read a pcap file
termshark -r capture.pcap

# capture with a display filter
sudo termshark -i eth0 -Y "http.request"

# filter to a specific conversation
termshark -r capture.pcap -Y "ip.addr == 10.0.0.1 && tcp.port == 443"
