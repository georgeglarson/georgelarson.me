## An ecosystem, not a product

Over the past year I've built a set of tools around Venice AI, a privacy-focused AI platform.

### venice-dev-tools
TypeScript SDK monorepo. npm packages, 170+ tests, rate limiting, retries, streaming. Calendar-versioned to stay in sync with the API.

### deep-research-privacy
Privacy-first AI research tool. Venice.ai models + Brave Search. Zero data collection, parallel queries, structured output with citations. 33 stars on GitHub.

### venice-mcp
Model Context Protocol server for Venice AI. Chat, image generation, TTS, embeddings.

### Plus
SDKs in Rust and PHP, monitoring tools, and integrations.

None of this was a job. I built it because I wanted better tooling for a platform I use. That's usually how the best SDKs happen.
